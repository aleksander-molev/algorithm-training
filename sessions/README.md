# Sessions

Each meaningful training session should create one Markdown file here.

File name format:

```text
YYYY-MM-DD-short-title.md
```

Examples:

```text
2026-09-13-initial-diagnostic.md
2026-09-15-sliding-window-review.md
2026-09-20-interview-session-01.md
```

Use `templates/session-template.md`.

Session files are chronological history. Do not duplicate all session details into `docs/progress.md`.
